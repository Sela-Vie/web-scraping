# THIS IS AN EASY WAY TO GET YOUR INSTAGRAM STATS

### PREREQUISITES

first download the html form the links
- this need to be on mobile mode after you inspect to load the page in the proper format
- load the whole page before you download by scrolling to the bottom of your followers/following page
```bash
"https://www.instagram.com/$YOUR_INSTAGRAM/followers/"
"https://www.instagram.com/$YOUR_INSTAGRAM/following/"
```

then download the venv for your jupyter notebook if you dont already have one
```bash
cd $ABSOLUTE_DIR_OF_PROJECT
./venv/bin/python3 -c pip install -r requirements.txt
```
after this, the jupyter notebook should be straighforwardly runnable
